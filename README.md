# HTML2

Segunda versión de mi primera página web (curso de Kodland). Parte de [HTML](https://github.com/ItsTuki/HTML) y le agrega animación y contenido embebido.

## Novedades respecto a la primera versión

- **Título animado:** el `<h1>` cambia de color en un ciclo tipo arcoíris usando `@keyframes` en CSS.
- **Widget del clima:** un `<iframe>` de [meteoblue](https://www.meteoblue.com) con el pronóstico de 4 días.
- Estilos separados para `h1` y `h2`.

## Cómo verla

Abre `index.html` en cualquier navegador (el widget del clima necesita conexión a internet).

## Estructura

```
index.html  # contenido de la página y widget del clima
style.css   # estilos y animación de color
```
